# apps/web

**UI de KOS** — React + TypeScript + Vite + Tailwind + shadcn/ui.

Interfaz tipo IDE (no tipo ChatGPT): explorador de conocimiento (izquierda), chat con planes visibles (centro), grafo interactivo (derecha), herramientas y trazas (abajo).

Solo habla con `apps/api` por HTTP; el cliente se genera desde OpenAPI.

- Se scaffoldea en el **Sprint 1** ([plan de sprints](../../docs/08-plan-de-sprints.md)).
