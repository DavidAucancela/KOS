# Cliente de la API — código GENERADO

Esta carpeta contiene únicamente código generado desde el OpenAPI de `apps/api`
(regla del repo, doc 09 §3: los tipos de la API no se escriben a mano).

Con la API corriendo en `localhost:8000`:

```bash
pnpm --filter kos-web generate:api
```

produce `schema.d.ts`. **No editar a mano.**
